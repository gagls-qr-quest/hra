## Ako na ňom pracovať

1. Naklonuj repozitár (GitHub Desktop alebo `git clone https://github.com/gagls-qr-quest/hra.git`).
2. Otvor priečinok vo VS Code a spusti **Live Server** (pravý klik na `index.html` → Open with Live Server).
3. Uprav kód, ulož, skontroluj v prehliadači (aj v režime mobilu v DevTools, F12).
4. `git add` → `git commit -m "Pridaj …"` → `git push`. O minútu je zmena na GitHub Pages.

Quest aj spoločná knižnica sa načítavajú z `https://gagls-qr-quest.github.io/`, takže lokálne
všetko funguje bez ďalších súborov. Ako spolu moduly hovoria: [FORMAT.md](https://github.com/gagls-qr-quest/gagls-qr-quest.github.io/blob/main/FORMAT.md).
